# Строитель — сайт строительной компании

Статический сайт без зависимостей и сборки на сервере. Netlify публикует корень репозитория.

## Редактирование

- `tools/build_pages.py` — тексты, список объектов и общие блоки пяти страниц.
- `assets/site.css` — оформление и адаптив.
- `assets/site.js` — мобильное меню, анимация появления, просмотр фотографий.
- `img/homes/` — исходные фотографии объектов.

После изменения текстов запустите `python3 tools/build_pages.py` и сохраните также обновлённые HTML-файлы. На Netlify Python не нужен: HTML уже готов.

## Проверка и локальный просмотр

```sh
python3 tools/check_site.py
node --check assets/site.js
python3 tools/serve.py
```

Просмотр: http://127.0.0.1:4330 . Сервер поддерживает адреса без `.html`, как Netlify.

Контакты и реквизиты сохранены из прежнего сайта. Заявки принимаются по телефону и email; скрытого обработчика форм нет. Карта Яндекса загружается при приближении к ней.
